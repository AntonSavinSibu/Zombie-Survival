How to Play

Get the game running in under a minute.

Requirements: Python 3.8+ and Pygame

# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/zombie-survival.git
cd zombie-survival

# 2. Install dependency
pip install pygame

# 3. Launch the game
python zombie.py

Optional: place gun sprites in a zombie_game_assets/ folder. The game runs fine without them.
